Linux OS Event Alarm System
A C-based Linux Operating Systems project that demonstrates process
creation, signal handling, child-process monitoring, and audible
alerts. The application creates a parent monitor and a child process,
listens for selected Linux signals, asks the user whether to accept or
reject termination requests, and plays an alarm sound when required.

Project Overview
The Linux OS Event Alarm System is a terminal-based application
developed in the C programming language for Linux. It demonstrates how a
process can respond to operating-system signals and monitor the
termination of a child process.

The application uses a parent process to monitor events and a child
process that runs for approximately five seconds before terminating
normally. The parent handles three signals:
- SIGTERM --- termination request.
- SIGINT --- keyboard interrupt, commonly generated by Ctrl+C.
- SIGCHLD --- notification that a child process has changed state,
  commonly because it has terminated.
When the parent receives SIGTERM or SIGINT, it displays an alert and
asks the user to enter Y or N. If the user accepts, the application
shuts down. If the user rejects the request, the application plays an
alarm sound and continues monitoring. When the monitored child exits,
the parent detects the event, displays an alert, and plays the alarm
sound.
Note: This project is an event-driven process and signal
demonstration. It is not a clock-based alarm scheduler and does not
currently monitor every type of Linux system event.

Problem Statement
Important operating-system events, such as process termination requests
and child-process termination, may go unnoticed if a user is not
actively monitoring a terminal. A simple clock alarm does not
demonstrate how an application can respond to Linux signals or process
events.

This project provides a Linux-based event alarm application that detects
selected signals, displays alerts, allows the user to accept or reject
termination requests, and generates an audible alarm for relevant
events.
Objectives
1. Create a parent process and a child process using the fork()
   system call.
2. Register signal handlers for SIGTERM, SIGINT, and SIGCHLD.
3. Detect signals using safe signal-handler flags.
4. Allow the user to accept or reject termination requests.
5. Play an alarm sound when a termination request is rejected.
6. Detect child-process termination using SIGCHLD.
7. Use waitpid() to collect child-process status.
8. Demonstrate important Linux Operating System concepts through a
   practical C application.
Features
- Parent and child process creation: Uses fork() to create a
  child process.
- Signal handling: Handles SIGTERM, SIGINT, and SIGCHLD.
- Termination confirmation: Asks the user to confirm or reject
  exit requests.
- Audible alarm: Plays alarm.wav using the Linux paplay
  utility.
- Child-process monitoring: Detects when the child process
  terminates.
- Process synchronization: Uses waitpid() to wait for and
  collect process status.
- Terminal alerts: Displays clear messages for detected events.

Signal Handling Design
The signal handler only sets a flag for the received signal. It does not
print messages, play audio, or ask for user input. The main monitoring
loop checks these flags and performs the required operations.

This keeps complex operations outside the signal handler.
How the Program Works
1. The application registers handlers for SIGTERM, SIGINT, and
   SIGCHLD.
2. It displays the parent process ID.
3. It creates a child process using fork().
4. The child displays its process ID, sleeps for approximately five
   seconds, and exits.
5. The parent displays the events being monitored and enters a
   monitoring loop.
6. When SIGTERM or SIGINT is received, the parent displays an alert
   and asks the user to enter Y or N.
7. If the user enters Y, the parent sends SIGTERM to the child if
   it is still running, waits for the child, and exits.
8. If the user enters N, the parent plays the alarm sound three times
   and continues monitoring.
9. When the child terminates, the parent handles the SIGCHLD
   notification, checks the child using waitpid() with WNOHANG,
   displays an alert, and plays the alarm sound.
10. After the monitored child has been collected, the parent continues
    running until the user accepts an exit request.

Limitations
- The current version handles only SIGTERM, SIGINT, and SIGCHLD.
- The child process exits automatically after approximately five
  seconds.
- The application is terminal-based and does not have a graphical user
  interface.
- Audible alerts depend on the paplay utility, an available audio
  service, and the alarm.wav file.
- It does not currently monitor file changes, CPU usage, memory usage,
  or network events.
- The monitoring loop uses sleep(1) polling rather than an
  event-waiting mechanism such as sigsuspend().
Technical Note
SIGCHLD can also be generated when the temporary child processes
created for paplay exit. The program uses
waitpid(child_pid, ..., WNOHANG) to distinguish the monitored child
from those temporary processes. For a more robust implementation, signal
blocking and pending-signal handling should be considered.

Complete Source Code
Save the following code as linux_event_alarm.c.
#define _POSIX_C_SOURCE 200809L

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <signal.h>
#include <sys/wait.h>
#include <sys/types.h>

volatile sig_atomic_t sigterm_received = 0;
volatile sig_atomic_t sigint_received = 0;
volatile sig_atomic_t sigchld_received = 0;

pid_t child_pid = -1;

/* Signal handler */
void signal_handler(int sig)
{
    if (sig == SIGTERM)
        sigterm_received = 1;
    else if (sig == SIGINT)
        sigint_received = 1;
    else if (sig == SIGCHLD)
        sigchld_received = 1;
}

/* Play alarm sound */
void play_alarm_sound(void)
{
    for (int i = 0; i < 3; i++)
    {
        pid_t sound_pid = fork();

        if (sound_pid == 0)
        {
            execlp("paplay", "paplay", "alarm.wav", (char *)NULL);
            perror("paplay");
            _exit(1);
        }
        else if (sound_pid > 0)
        {
            waitpid(sound_pid, NULL, 0);
        }
        else
        {
            perror("fork");
        }
    }
}

/* Display alarm notification */
void show_alert(const char *message)
{
    printf("\n");
    printf("=============================================\n");
    printf("          LINUX OS EVENT ALARM\n");
    printf("=============================================\n");
    printf("ALERT: %s\n", message);
    printf("=============================================\n");
}

/* Get Y/N choice from user */
char get_choice(void)
{
    char choice;

    while (1)
    {
        printf("Enter choice [Y/N]: ");
        fflush(stdout);

        if (scanf(" %c", &choice) == 1)
        {
            while (getchar() != '\n')
                ;

            if (choice == 'Y' || choice == 'y' ||
                choice == 'N' || choice == 'n')
            {
                return choice;
            }
        }

        printf("Please enter Y or N.\n");
    }
}

int main(void)
{
    struct sigaction sa;

    sa.sa_handler = signal_handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;

    /* Register Linux signal handlers */
    sigaction(SIGTERM, &sa, NULL);
    sigaction(SIGINT, &sa, NULL);
    sigaction(SIGCHLD, &sa, NULL);

    printf("=============================================\n");
    printf("       LINUX OS EVENT ALARM SYSTEM\n");
    printf("=============================================\n\n");

    printf("Main Monitor PID : %d\n", getpid());

    /* Create child process */
    child_pid = fork();

    if (child_pid < 0)
    {
        perror("fork");
        return 1;
    }

    if (child_pid == 0)
    {
        printf("Child Process PID : %d\n", getpid());
        printf("Child will finish automatically after 05 seconds.\n");
        printf("\nMonitoring OS events...\n");
        fflush(stdout);

        sleep(5);

        printf("\nChild process is terminating normally.\n");
        _exit(0);
    }

    printf("Child PID         : %d\n", child_pid);
    printf("\n");
    printf("Events being monitored:\n");
    printf("1. SIGTERM - Termination request\n");
    printf("2. SIGINT  - Keyboard interrupt (Ctrl+C)\n");
    printf("3. SIGCHLD - Child process termination\n");
    printf("\n");
    printf("System is ready.\n");
    printf("=============================================\n");

    while (1)
    {
        /* EVENT 1: SIGTERM */
        if (sigterm_received)
        {
            sigterm_received = 0;

            show_alert("Termination request (SIGTERM) received.");

            char choice = get_choice();

            if (choice == 'Y' || choice == 'y')
            {
                printf("\nTermination accepted.\n");
                printf("The alarm system will now terminate.\n");

                if (child_pid > 0)
                {
                    kill(child_pid, SIGTERM);
                    waitpid(child_pid, NULL, 0);
                }

                printf("Process terminated successfully.\n");
                return 0;
            }
            else
            {
                printf("\nTermination rejected.\n");
                printf("The alarm system will continue running.\n");
                printf("Playing alarm sound...\n");

                play_alarm_sound();

                printf("Monitoring continues.\n");
            }
        }

        /* EVENT 2: SIGINT */
        if (sigint_received)
        {
            sigint_received = 0;

            show_alert("Keyboard interrupt (SIGINT / Ctrl+C) received.");

            char choice = get_choice();

            if (choice == 'Y' || choice == 'y')
            {
                printf("\nExit request accepted.\n");
                printf("Shutting down alarm system...\n");

                if (child_pid > 0)
                {
                    kill(child_pid, SIGTERM);
                    waitpid(child_pid, NULL, 0);
                }

                printf("Process terminated successfully.\n");
                return 0;
            }
            else
            {
                printf("\nExit request rejected.\n");
                printf("The alarm system will continue running.\n");
                printf("Playing alarm sound...\n");

                play_alarm_sound();

                printf("Monitoring continues.\n");
            }
        }

        /* EVENT 3: SIGCHLD */
        if (sigchld_received)
        {
            int status;
            pid_t result;

            sigchld_received = 0;

            result = waitpid(child_pid, &status, WNOHANG);

            if (child_pid > 0 && result == child_pid)
            {
                show_alert("Child process has terminated (SIGCHLD received).");

                printf("Child PID %d has ended.\n", child_pid);
                printf("Playing alarm sound...\n");

                play_alarm_sound();

                printf("Parent monitor is still running.\n");

                child_pid = -1;
            }
        }

        sleep(1);
    }

    return 0;
}
Troubleshooting
1. paplay: command not found
Install the audio utility:
sudo apt install pulseaudio-utils
2. Alarm sound is not playing
- Check that alarm.wav exists in the current working directory.
- Check that paplay is installed using which paplay.
- Check that your Linux audio service is running.
- Try playing the file manually:
paplay alarm.wav
3. GCC compiler not found
Install GCC:
sudo apt update
sudo apt install build-essential
4. Permission denied
Make sure you have permission to access the project directory and its
files. You can compile and run the program from your own project
directory.
